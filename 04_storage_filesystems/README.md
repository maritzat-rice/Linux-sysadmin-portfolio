# Storage & Filesystems (Mount Points, NFS, Storage, Kernel Backups)

This folder contains hands-on Linux storage and filesystem administration tasks. These exercises demonstrate practical experience with creating mount points, configuring NFS shares, managing storage requests, and performing kernel backup operations in enterprise environments.

---

## 📌 Overview

The tasks in this folder cover:

- Creating mount points for upcoming NFS shares  
- Permanently mounting NFS resources  
- Configuring NFS home directories  
- Managing storage allocation requests  
- Creating backups for server kernels  
- Configuring and validating NFS server functionality  

These workflows reinforce core Linux storage fundamentals and highlight my ability to manage filesystems across distributed environments.

---

## 📁 Task Breakdown

### **Create Mount Points**
Created required directory structures for incoming NFS shares.  
Ensured proper hierarchy and verified mount point readiness.

---

### **Mount NFS Shares Permanently**
Configured persistent NFS mounts using `/etc/fstab`.  
Validated connectivity, permissions, and mount stability across reboots.

---

### **NFS Home Directory Configuration**
Set up NFS-based home directories for centralized user management.  
Verified correct mounting behavior and user access.

---

### **Create Backups for Server Kernel**
Performed kernel backup operations to ensure recovery capability.  
Validated backup integrity and documented storage location.

---

### **Storage Request**
Processed and fulfilled storage expansion or allocation requests.  
Ensured proper provisioning and updated system documentation.

---

### **Configure NFS Server**
Configured an NFS server to export directories to client systems.  
Set permissions, updated export rules, and validated client access.
