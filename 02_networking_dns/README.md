# Networking & DNS Configuration

This folder contains hands-on networking tasks focused on configuring static IP connections, validating DNS resolution, and ensuring proper connectivity for Linux servers. These tasks demonstrate foundational networking skills essential for Linux System Administration and enterprise infrastructure environments.

---

## 📌 Overview

The tasks in this folder cover:

- Static IP configuration  
- Network interface setup using `nmcli`  
- Internal and external connectivity validation  
- DNS resolution testing  
- Local user creation and privilege assignment  
- Asset inventory updates for documentation and tracking  

*These workflows reinforce core networking fundamentals and ensure reliable connectivity for Linux-based systems.*

---

## 📁 Task Breakdown

### **Static IP Network Setup**
Configured a static IP connection for a development server using information from the IP Address Management (IPAM) sheet.  
Validated gateway reachability, external connectivity, and DNS resolution.  
Created a local administrative user and updated asset inventory records.

---

### **Create Static Connection**
Established a static network connection for a staging web server.  
Applied correct IP, gateway, netmask, and DNS settings.  
Verified connectivity and DNS functionality.  
Created and configured a privileged local user and updated asset inventory.

---

### **DNS Resolution**
Performed DNS resolution tests to confirm proper name lookup functionality.  
Validated that DNS servers respond correctly and that hostname resolution is functioning as expected.
