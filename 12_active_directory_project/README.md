# Active Directory Project

## Overview
This project demonstrates core Active Directory (AD) administration skills through a structured, ticket‑based workflow. Each ticket represents a real‑world SysAdmin task performed inside **Active Directory Users and Computers (ADUC)**, including OU management, user creation, group creation, and verification of AD object properties.

All tasks were completed in a controlled domain environment and documented with clear steps, verification, and screenshots for portfolio/interview readiness.

---

## Tickets Included in This Project

### Managing Active Directory
Initial project setup and validation of AD access.  
Includes domain navigation, environment overview, and confirmation of administrative tools.

### Access Active Directory Services
Verifies successful access to ADUC and ability to perform basic AD operations.  
Includes user creation, group creation, and password reset validation.

### Create New Organizational Unit (OU)
Confirms the presence and configuration of the required OU under the VITI container.  
Ensures correct naming and protection settings for the **mrice‑VITI** OU.

### Create New User
Creates a new AD user inside the designated OU.  
Includes account configuration, password settings, and verification of user object properties.

### Create New User Group
Creates a new security group with Global scope and Security type.  
Adds the AD user **mrice82** as a member and verifies group membership and protection settings.
