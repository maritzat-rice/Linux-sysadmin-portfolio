# Web Services (Apache, MariaDB, PHP, LAMP, WordPress, FTP)

This folder contains hands-on web service administration tasks performed in a Linux and vSphere environment. These tasks demonstrate practical experience with deploying web servers, configuring Apache, installing PHP, managing LAMP stacks, updating web content, deploying WordPress containers, and configuring FTP services.

---

## 📌 Overview

The tasks in this folder cover:

- Deploying web servers from vSphere templates  
- Installing and configuring Apache  
- Managing and updating web content  
- Installing PHP and required extensions  
- Deploying full LAMP stacks  
- Running WordPress using Docker containers  
- Configuring FTP server and client  
- Troubleshooting and validating web service functionality  


---

## 📁 Task Breakdown

### **Deploy Development Web Server Using Template**
Provisioned a development web server from a vSphere template.  
Configured hostname, static networking, IPA client, NFS mount points, and local administrative user.  
Updated asset inventory with server metadata.

---

### **Install Apache**
Installed and validated Apache web server functionality.  
Confirmed service status, ensured proper startup behavior, and prepared the server for hosting web content.

---

### **Configure Apache Web Content**
Updated and deployed custom web content to the Apache document root.  
Validated content rendering and ensured correct permissions and ownership.

---

### **Update Web Content for ariclaw**
Modified and deployed updated content for the ariclaw site.  
Ensured proper placement, formatting, and accessibility through Apache.

---

### **Provide Apache Version**
Retrieved and documented the Apache version using system commands.  
Verified installation and module availability.

---

### **Fix Issue on Web Server**
Troubleshot and resolved a web server issue affecting content delivery or service behavior.  
Validated service recovery and confirmed proper functionality.

---

### **Install PHP**
Enabled PHP module streams, installed PHP 8.x and required extensions, restarted Apache, and validated PHP processing using a temporary test page.

---

### **Install LAMP Stack**
Installed and configured Linux, Apache, MariaDB, and PHP components.  
Validated service functionality and ensured proper integration between stack layers.

---

### **Deploy WordPress Docker Containers**
Deployed WordPress using Docker containers.  
Configured container networking, volumes, and database connectivity.  
Validated successful WordPress startup and accessibility.

---

### **Configure FTP Server & Client**
Installed and configured FTP server and client tools.  
Set up user access, validated connectivity, and ensured secure file transfer operations.

---
